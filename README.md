# Crowdsourcing Data Bencana

Repo ini adalah simulasi platform untuk mengumpulkan
dan memverifikasi laporan kebutuhan bencana dari
relawan lapangan secara terbuka dan cepat.

## Cara Melapor

Relawan dapat membuat Issue baru menggunakan template
"Laporan Bencana" untuk melaporkan lokasi terdampak
dan kebutuhan mendesak.

## Status Verifikasi

Setiap laporan yang masuk akan diberi label berikut:
- `belum-diverifikasi` - laporan baru, belum dikonfirmasi
- `terverifikasi` - laporan sudah dikonfirmasi tim koordinasi
